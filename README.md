Todo el contenido está en un solo archivo: [`perfil.yml`](perfil.yml). Cuando se guarda un cambio aquí, la página se actualiza sola en unos minutos.

## Cómo se edita

Esta página se edita con un asistente de IA conectado a GitHub:

- **Claude:** entra a claude.ai/code, conecta tu GitHub y elige este repositorio con la rama `main`.
- **ChatGPT:** usa Codex o ChatGPT Work con tu GitHub conectado y elige este repositorio.

Pídelo en lenguaje normal, por ejemplo:

> Agrega a mi perfil este artículo: https://doi.org/... y actualiza mi semblanza con este párrafo: ...

El asistente sigue las reglas de [`AGENTS.md`](AGENTS.md): solo cambia tu perfil, no inventa datos y te muestra el cambio antes de guardarlo. Al guardarlo en `main`, la página se actualiza sola en unos minutos.

**Red de seguridad:** después de cada cambio, GitHub revisa `perfil.yml` automáticamente. Si encuentra un error, regresa el archivo a la versión anterior por sí solo, para que la página nunca quede rota, y te avisa por correo. Pídele a tu asistente que lo corrija y vuelva a guardarlo.

## Tu foto

Pídele a tu asistente que use el enlace de tu foto, o que guarde la imagen en este repositorio. Se muestra en círculo. Si la cara queda pequeña o descentrada, pídele que ajuste:

- `foto_zoom: 1.4` acerca la imagen (1 = sin acercar).
- `foto_posicion: "50% 0%"` elige qué parte se ve (horizontal y vertical; `0%` = arriba).
